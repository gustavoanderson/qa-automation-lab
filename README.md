# QA Automation Lab

Repositório de projetos práticos de estudo em Quality Assurance e automação de testes — parte de um desafio pessoal de transição de carreira para QA.

Cada pasta é um projeto independente: um pequeno app/protótipo construído com boas práticas de qualidade desde o início, acompanhado de um relatório de QA descrevendo os cuidados tomados e os testes realizados.

## Projetos

- [`tic-tac-toe/`](./tic-tac-toe) — Jogo da velha (HTML/CSS/JS puro), com guardas de QA contra cliques inválidos/duplos, acessibilidade por teclado e leitor de tela, e testes automatizados da lógica de vitória. Veja o [relatório de QA](./tic-tac-toe/QA-REPORT.md).
